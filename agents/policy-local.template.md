# Política Local dos Agentes

A política base vem do `obsidian-config` (`agents/policy.md`) e vale para todos os agentes. Esta nota guarda só o que é específico deste vault e prevalece sobre a base em caso de conflito.

Bons candidatos para esta nota:

- convenções de porta, ambiente ou deploy das suas organizações;
- integrações obrigatórias (observabilidade, CI) e as exceções a elas;
- procedimentos de validação de UI específicos de um sistema;
- incidentes que viraram regra, com data e causa.
